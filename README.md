### Генерация синтетических данных

Скрипт generators.py содержит расширенный набор провайдеров для библиотеки Faker, позволяющий генерировать реалистичные российские документы, авиаданные, номера билетов, имена, PNR-коды, FFP-номера и т.д.

Используется для производства синтетических примеров NER, имитирующих реальные пользовательские данные.

Процесс настройки генерации:
* Найдите класс и метод, генерацию которого вы ходите изменить в generators.py;
* Найдите список formats = [...];
* Закомментируйте те строки форматов, которые НЕ должны появляться в итоговой выборке.

Если вы расширяете функциональность генератора и добавляете собственные классы документов или новые методы, то рекомендуется придерживаться следуюего порядка действий:
* Реализуйте новый класс-провайдер (наследуйте его от BaseProvider и реализуйте методы генерации нужных значений);
* Подключите провайдер внутри setup_faker_providers();
* При необходимости добавьте делегирующие методы в RussianAviationProvider;
* Добавьте новый тип документа в get_all_document_types().

Генерация синтетических значений для тегов происходит автоматически при запуске файла statics.py.
В момент его выполнения создаётся экземпляр Faker, к которому подключаются все кастомные провайдеры через функцию setup_faker_providers():
После этого все методы, добавленные в ваши классы-провайдеры становятся доступны через объект 'fake'.
Словарь DATAGEN использует эти методы для генерации значений по каждому тегу.

###  Тестировка

Скрипт tester.py выполняет полное пост-обученческое тестирование модели NER и формирует детальный анализ качества работы модели. Он поддерживает строгую BIO-оценку через библиотеку seqeval, 
а также строит несколько видов матриц ошибок для визуального анализа.

Для запуска процесса тестировки:
* Загрузите тестовый датасет (путь к файлу указывается в переменной TEST_DATA_PATH:);
* Загрузите обученную модель spaCy (путь задаётся в MODEL_PATH:);
* Запустить данный файл.

При оценке модель получает набор показателей для каждой сущности и общий итог:
* precision - сколько найденных сущностей оказались правильными;
* recall - какую долю реальных сущностей модель смогла найти;
* f1-score - гармоническое среднее между precision и recall;
* support - количество примеров сущности в датасете.

Если модель не умеет определять какие-то сущности, то seqeval выдаст ошибку, что модель не определила какие-то сущности, но не остановит оценку.

В ходе тестировки будут созданы 3 матрицы ошибок, а также проведён анализ работы модели в общем, по сущностям, а также по разметке границ сущностей в тестировочном наборе данных. Анализ работы модели будет выведен в консоль.

Матрицы ошибок показывают:
* Строки - истинные метки;
* Столбцы - предсказанные метки;
* Диагональ - правильные определения;
* Остальные ячейки - конкретные типы ошибок

Первая таблица показывает, сколько раз модель предсказала каждую сущность, включая ошибки.
Вторая таблица - это нормализованная версия матрицы ошибок, где каждая строка приведена к процентам.
Третья таблица выводит N наиболее частых ошибок (по умолчанию top_n = 15. Можно изменить значение на нужное количество ошибок).

Все параметры, влияющие на внешний вид и содержимое графиков, находятся непосредственно внутри вызовов '_plot_heatmap(...)', а также в реализации самой функции '_plot_heatmap(...)'.
Визуализация формируется с помощью библиотеки matplotlib.

### Fine-tuning
В SpaCy отсутсвует функция продолжения обучения с сохранением всех старых весов - модель фактически пересчитывает веса заново при каждом запуске тренировки.
Можно настроить процесс так, чтобы изменения затрагивали старые параметры минимально, и модель "осторожно" адаптировалась к новым данным, не "разрушая" уже изученные знания.

Для корректного "дообучения" модели важно:
* Смешивать старые и новые данные (70% старых данных, 30% новых данных. Для лучшего результата нужно предварительно перемешать, чтобы модель обучалась на равномерном рспрежедении);
* Маленький learning rate (рекомендуемые значения для новой сущности: 0.0001; обучение сущности, похожей на существующие: 0.00005; тонкая настройка с максимальной осторожностью: 0.00001);
* Небольшой dropout (0.05 или 0.1)

Эти изменения можно сделать в файле config.cfg или в скрипте trainer.py:
* Если вы хотите дообучать уже обученную модель, нужно вместо 'spacy.blank("ru")' загрузить её через 'spacy.load()'
* Для изменения learning rate - изменить (config["training"]["optimizer"]["learn_rate"])
* Для изменения dropout - изменить (config["training"]["dropout"])

Для ускорения процесса можно распределить обучение через SpaCy Ray.
Также можно использовать метод 'Pseudo-Rehearsal'.
